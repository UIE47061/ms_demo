# Eco-Sensing：Power BI / Microsoft Fabric 匯入說明

此資料包可匯入真正的 Power BI／Fabric。內容仍是虛構公司與範例估算資料，基準日為 2026/10/27，並非正式溫室氣體盤查。檔案不包含登入資訊或 API Key。

## 先在瀏覽器 Power BI 建立報表

1. 開啟 https://app.powerbi.com/ 並登入學校／公司帳號。
2. 進入你可建立內容的工作區，例如「我的工作區」。
3. 選擇「新增項目 → 語意模型」，資料來源選 Excel。選取 `Eco-Sensing-PowerBI-Seed.xlsx`，在資料選取器選擇命名資料表 `EcoEvents` 與 `EcoMonthlyTrend`。不要重複選取相同工作表與資料表。
4. 若介面提示先選連線，使用 Excel 活頁簿／從本機上傳檔案的流程。各組織的新介面可能不同；詳見下方 Microsoft 官方教學。
5. 完成資料類型檢查後建立報表。日期欄位為日期／日期時間，排放欄位為小數，`mock_data` 為布林值。
6. 建立下方的圖表並儲存為「Eco-Sensing 永續總覽」。
7. 複製瀏覽器的報表網址，回到 Eco-Sensing `/admin/analytics`，展開「匯入步驟與報表網址設定」，貼上並儲存。之後可由網站直接開啟真正的 Power BI 報表。

Excel 範例含初始 56 筆事件。若要匯入剛剛掃描或新增的事件，請從網站下載「目前篩選事件 CSV」，再以 Text/CSV 來源匯入或更新同名來源。這是手動快照交換，不會即時自動同步。

## 建議的第一頁報表

| 圖表 | 資料表與欄位 |
| --- | --- |
| 估算排放卡片 | EcoEvents.emission_kg_co2e，彙總選「總和」 |
| 另列避免排放卡片 | EcoEvents.avoided_kg_co2e，彙總選「總和」，不可自總排放扣除 |
| 參與員工卡片 | EcoEvents.employee_id，彙總選「相異計數」 |
| 部門比較長條圖 | department 為類別，emission_kg_co2e 總和為值 |
| 來源分布圓環圖 | source_name 為類別，emission_kg_co2e 總和為值 |
| 近期每日趨勢 | event_date 為日期，emission_kg_co2e 總和為值 |
| 部門與日期篩選器 | department、event_date |
| 六個月趨勢（獨立圖表） | EcoMonthlyTrend.month_start 為日期，emission_kg_co2e 總和為值；source_name 可作圖例 |

初始事件的核對值：56 筆事件、12 位參與員工、估算排放 698.26 kg CO₂e、另列避免排放 3.50 kg CO₂e。

## Fabric 瀏覽器版

1. 開啟 https://app.fabric.microsoft.com/ 並選擇有 Lakehouse 建立權限的工作區。
2. 建立 Lakehouse，例如 `EcoSensing`。若沒有建立選項，需要管理員開放功能或可用容量，請勿為了本次操作自行購買方案。
3. 在 Lakehouse 的 Files 上傳 `EcoEvents.csv` 與 `EcoMonthlyTrend.csv`。
4. 對各 CSV 選「Load to tables → New table」。設定首列為標題、UTF-8、逗號分隔；檢查數字、布林值與日期欄位。
5. 由 Lakehouse 建立語意模型，再建立 Power BI 報表，依上方欄位配置圖表。

## 兩張資料表的用途

### EcoEvents

每列是一筆事件，供本月、員工、部門與來源分析。`event_date` 是活動日期，`occurred_at_local` 是臺北時間的呈現時刻（不作 UTC 轉換）。`emission_kg_co2e` 與 `avoided_kg_co2e` 是獨立量值。`employee_name` 為虛構人物。

### EcoMonthlyTrend

每列是「月份 × 排放來源」。5–9 月是全公司的獨立歷史彙總；10 月是目前事件的來源加總。歷史月份沒有部門分布，亦未收錄避免排放，相關欄位保持空白。`data_layer` 與 `coverage_note` 說明資料範圍。

**不要將 EcoEvents 與 EcoMonthlyTrend 的排放直接相加，否則會重複計算 10 月。**兩張表不需要為本次操作建立關聯；六個月趨勢使用 EcoMonthlyTrend，其餘本月圖表使用 EcoEvents。歷史趨勢不可套用部門拆分來冒充真實部門數據。

## 可選 DAX 量值

若匯入後的表名是 EcoEvents，可建立以下量值；也可直接使用欄位總和／相異計數。

```dax
估算排放 = SUM(EcoEvents[emission_kg_co2e])
另列避免排放 = SUM(EcoEvents[avoided_kg_co2e])
參與員工 = DISTINCTCOUNT(EcoEvents[employee_id])
事件筆數 = COUNTROWS(EcoEvents)
月度排放 = SUM(EcoMonthlyTrend[emission_kg_co2e])
```

這裡每行是獨立量值，不要整段貼進同一個量值編輯器。碳幣與 EXP 未混入排放資料。

## 開啟與嵌入

網站可以直接開啟已儲存的報表連結，這不會替使用者登入、授予權限或同步資料。若之後要嵌入網站，需使用 Power BI 提供的安全嵌入方式，並符合帳號、報表權限與授權／容量條件；不使用公開發布來繞過權限。

本資料包提供 Excel／CSV 匯入來源，不是已完成圖表的 PBIX／PBIT 檔。真正的語意模型與視覺報表須在 Power BI／Fabric 儲存後才存在。
