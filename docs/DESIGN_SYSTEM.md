# Eco-Sensing：員工成長 × Microsoft 行動流程

以比賽現場約 90 秒的四段手動導覽為主要呈現入口，同時保留完整員工 App 與企業工作台。

## 視覺與資訊層級

- 白／暖白與中性灰為基礎，森林綠代表員工行動，Azure 藍代表 AI 流程，Teams 紫代表提醒，金黃代表激勵與分析。顏色用於具體情境，不代表服務已連線。
- 精緻扁平 SVG：辦公室、成長花盆、碳魔王共用輪廓、葉片與色彩，不依賴外部圖片。無像素字體、永久晃動或滿版遊戲 HUD。
- 首頁採大主題與辦公室場景；員工首頁以花盆為視覺焦點；主管總覽以主數據與一項篩選後洞察為焦點。詳細圖表與紀錄置於後續區域。
- 任務頁以碳魔王呈現本輪進度；排行以名次與積分為主；個人頁呈現任務衍生新葉與原有成就。

## 四段呈現

`/demo` → 高鐵憑證與 AI 接力 → 智慧回收 → Teams 提醒 → 主管分析。

導覽由呈現者手動前進、退回、略過或退出；沒有倒數、自動提交、自動掃描或進入時重設。導覽中的每個操作都使用正式頁面與同一份 Demo 狀態。開始時保留目前紀錄。

## Microsoft 的具體位置

- 差旅頁顯示 Document Intelligence、Foundry、AI Search 的欄位／解析／參考資料／校驗接力。完成後可查看 `Eco-Sensing 本機資料集 v1 · 2026/10/27`，非官方係數；手動修改後明確標記人工確認。
- 垃圾桶頁顯示裝置 → IoT Hub → 處理與歸戶 → 個人紀錄。
- Teams 小幫手預設離座提醒。「一鍵休眠」完成原有 `power` 任務並依原有規則領獎；「我還要用」僅暫緩提醒。不控制電腦、不傳訊息、不新增排放或避免排放。
- 個人問答與主管 Data Agent 提供預設問題，答案直接由目前事件、任務及篩選條件計算，非通用 AI。顯示期間、事件筆數及相關事件。
- Microsoft 流程頁讓觀眾點選服務分工，涵蓋 IoT Hub、Graph、Document Intelligence、Foundry、AI Search、Fabric、Container Apps、Teams、Copilot Studio、Power BI 及 Entra ID。
- 服務畫面一律標示「本機預覽模式」。圖表由 Recharts 呈現；不冒稱 Power BI 嵌入、不宣稱官方里程查核或雲端部署。

## 狀態與成長

原有 `DemoState`、`CarbonEvent`、種子資料、localStorage 格式與排放／領獎規則不變。

- 葉片＝既有任務中已領獎的唯一任務數。
- 魔王 HP＝`round(100 × (1 − 已領獎數 / 任務總數))`。
- 等級仍為 `floor(EXP / 500) + 1`，不另創平行等級。
- 遊戲進度不抵銷排放，不代表碳權或正式減碳量。
- 導覽／Teams 暫緩使用獨立呈現層 Context 與 sessionStorage，不寫入原有業務資料。共用重設按鈕同時還原兩層狀態。

## 手機、鍵盤與動態

員工端主要按鈕至少 44px，掃描操作固定在底部導覽上方並支援 safe area。企業端保留桌面 Sidebar 與手機抽屜。導覽置於頂部，版面保留實際高度，避免壓住標題。原生 dialog、Escape、focus-visible、跳至內容功能沿用。

動畫僅用於掃描、生成、領獎後植物成長及 HP 變化，遵循 reduced motion。列印僅保留報告文件，隱藏導覽及控制介面。
