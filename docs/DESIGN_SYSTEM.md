# Eco-Sensing 視覺與互動系統

## 視覺語言

以簡報中的「辦公室打怪」延伸為可使用的產品：奶白底色、森林綠文字、圓潤但清楚的字重、細描邊自製向量插畫。角色包含綠色夥伴與碳魔王；辦公室、差旅、回收、Teams 和分析使用同一套線條與配色。不使用像素字體或滿版遊戲介面。

## 字體與元件

數字、英文使用本機打包的 Inter；中文使用繁體中文系統字體。標題以字重與尺度建立焦點：入口桌面 44–70px、手機 38–51px；工作空間主標 24–28px；數據使用等寬數字。4px 間距節奏，卡片 10–17px、場景外框 24px、按鈕 9px 圓角。表格仍以列、分隔線與對齊比較資料，沒有轉成圖片卡片。

向量插畫全部由 `ActionArt.tsx` 與 `Illustrations.tsx` 產生，不依賴外部圖片伺服器。場景不是固定數據海報：HP、植物葉片與等級沿用共用的已領獎任務與 EXP。

## 動態效果

「播放行動場景」會依序呈現列車移動、提醒卡出現與植物成長，約 5 秒結束，可重播。不自動加入事件或發獎。領獎時植物成長一次，任務頁的碳魔王短暫震動、明暗閃動，並顯示本次實際扣除的 HP，650ms 後結束；重新進頁不重播。沒有持續漂浮、倒數提交或遮住內容的入場淡入。`prefers-reduced-motion: reduce` 關閉上述動態與轉場。

## 版面與操作

- 員工端頂部使用不透明暖白背景，不使用色條、模糊或陰影；手機瀏覽器主題色跟隨頁面背景。員工端手機優先：固定底部導覽、可單手操作的掃描入口；花盆是首頁焦點。320px 保持無橫向溢出。
- 企業端桌面優先：左側固定導覽、中性表格、單一主 KPI 與動態洞察。平板與手機使用收合導覽。
- 所有原有路由、篩選、登錄、領獎、審核、列印與本機資料重設保留。
- `/guide` 為行動導覽主入口；`/demo` 保留舊連結相容。旅程只改變呈現層，不自動清除原有活動。
- 使用者介面移除開發階段的標籤；資料來源與處理方式仍明確說明本機模式、預設欄位、人工確認與服務連線狀態。
- 正式產物使用 HashRouter，公共資料下載遵循 Vite `BASE_URL`，支援 GitHub Pages repository 子路徑。

## 驗收

主要畫面位於 `docs/screenshots/`。完整測試截圖與列印產物產生至 `test-results/`，不納入 Git。

## 員工端資訊架構更新（2026/10/29）

員工端以快速記錄為優先。底部固定四項導覽：首頁、碳足跡、任務、我的。排行榜保留原路由，入口移至任務與個人頁；排行榜頁維持任務選中狀態。

- 首頁：成長摘要、回收／差旅入口、單項待辦、足跡摘要；不重複放圖表與完整活動。記錄入口在 320px 與 390px 首屏可見。
- 足跡：期間與來源置頂，共同作用於「總覽／紀錄」。每日趨勢按需展開；紀錄分日，點擊可看活動詳情。`?view=records` 可直接開啟紀錄。
- 任務：先列可領獎項目；使用具體動作名稱，長說明與 EXP 留在詳情。差旅、回收及節能任務直接連到對應流程。魔王挑戰在頁面頂部直接顯示；計分規則改為列表底部小字。
- 個人：恢復插畫版，直接呈現個人資料、碳幣／總 EXP／已完成任務、植物與成就；資料管理保留獨立分組。通知／摘要開關實際控制首頁對應內容；通知為本機呈現，不會傳送系統通知。
- 小幫手：「提醒／問答」分開；選擇預設問題後才出現答案。未連線服務與不控制電腦的界線仍可見。
- 差旅／回收：專注流程隱藏底部導覽，頂部提供關閉。未提交資料保留於本分頁 sessionStorage；關閉時可保留或放棄。圖片不儲存。草稿不新增事件、不發獎，提交後與重設時清除。
- 回收五階段保留於詳情，處理中只突出當前狀態。完成畫面提供符合資格的原地領獎，沿用 `claimReward`，同一任務仍只能領取一次。
- 插畫僅用於入口與成長；長說明採展開閱讀，不縮小主要操作文字。輸入框至少 16px，主要觸控目標至少 44px。

以 `employee-ux.css` 限定員工工作空間樣式，不改動企業端資料分析密度。保留既有 localStorage、排放聚合、排名、任務獎勵與 Microsoft 服務界線。
